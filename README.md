# Next Generation Legacy – Kingdom Fields website

A responsive, one-page website built with plain HTML, CSS, and JavaScript. It has no paid theme, no build step, and no required backend.

## Included
- Institutional visual identity: forest green, warm gold, cream, and editorial serif typography
- Sections for the vision, six pillars, focus initiatives, the long-term Kingdom Fields concept, guiding principles, getting involved, and contact
- Responsive mobile navigation and accessible form labels
- Contact form that prepares an email through the visitor's own email app
- Copy that distinguishes the long-term vision from confirmed operating programs

## Before publishing
1. Open `script.js` and replace `YOUR_EMAIL_HERE` with the real email address for inquiries.
2. In `index.html`, replace `YOUR_EMAIL_HERE` in the three “Get involved” mail links with the same real address.
3. Verify the wording and add only confirmed facts: legal status, founder/team bios, current projects, location, contact details, partners, photos, results, and social links.
4. If the Unsplash hero image or Google Fonts are not wanted, remove their external references in `styles.css` and `index.html`.

## Publish free with GitHub Pages
1. Create or sign in to a GitHub account.
2. Create a new public repository, for example `kingdom-fields`.
3. Upload `index.html`, `styles.css`, `script.js`, and this README to the repository's root.
4. Open **Settings → Pages**.
5. Under build/deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
6. Wait for the Pages URL to appear. It usually looks like `https://YOUR-USERNAME.github.io/kingdom-fields/`.

## Alternative free host
Netlify can publish a static site by letting you drag and drop the folder or by connecting a GitHub repository. Follow the host's current setup prompts.

## Important limitations
- This is a static site. The contact form opens the visitor's email program; it does not save messages on a server.
- No domain is purchased or connected by this package. Hosting can be free on a provider's free tier; a custom domain may cost money.
- The site uses a remote hero photograph from Unsplash and Google Fonts, so those elements require an internet connection.
- The copy presents Kingdom Fields as a long-term vision and avoids claiming unverified achievements, completed facilities, funding, or active programs.
